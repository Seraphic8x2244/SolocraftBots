# SoloCraft Bots

A compact `.partybot` controller for SoloCraft on Vanilla WoW 1.12.1.

## Features

- Summon faction-valid bots by class and role/spec
- Direct controls for All, Target, Tank, Healer, Melee and Ranged bots
- Focus/CC raidmark assignments
- Saved 10-player presets with ordered groups and draggable live-player slots
- Collapsible UI, key binding support and `/reload`-safe settings
- FillRaidBots compatibility via `PCPFrameRemake`

## Commands

Open or close SoloCraft Bots with `/scb` or `/solocraftbots`. You can also assign **SoloCraft Bots** in WoW's Key Bindings menu.

## Install

Copy the `SoloCraftBots` folder into `Interface/AddOns/`.

SoloCraft Bots is written for SoloCraft's `.partybot` commands and requires no DLLs or other addons.
