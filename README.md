# SoloCraft Bots

A compact `.partybot` controller for SoloCraft on Vanilla WoW 1.12.1.

## Features

* Summon faction-valid bots by class and role/spec
* Presets: summons group-ordered presets for parties and raids
* Live-player placement and role handling in presets
* Send presets to other SoloCraft Bots users
* Request another player to summon your preset
* Kick All/Dead safely
* Refill missing preset bots
* Direct controls for All, Target, Tank, Healer, Melee and Ranged bots
* Focus/CC raidmark assignments
* Auto Loot controls
* Collapsible UI, key binding support and `/reload`-safe settings

## Commands

Open or close with `/scb` or `/solocraftbots`. You can also assign **SoloCraft Bots** in WoW's Key Bindings menu.

## Install

Copy the `SoloCraftBots` folder into `Interface/AddOns/`.

Requires SoloCraft `.partybot` commands. No DLLs or other addons required.
